ABOUT PROJECT

Smart Crop Yield Prediction

This project estimates the dataset's crop-yield target from historical agricultural and environmental inputs. Input quantities are normalized before inference. Output units are not harmonized across every crop in the source data, so the app reports the source-native yield scale rather than inventing a universal tonne value.
